# Fork lineage

This repository was created as a fork of Google's
[Elephant-Goldfish Model (`google/elephant-goldfish-model`)](https://github.com/google/elephant-goldfish-model).
The upstream project provides the EGM design, software-planning workflows,
reviewer personas, and much of the cross-agent packaging structure.

This copy is maintained independently as
[`RustyDrops/elephant-goldfish-dining`](https://github.com/RustyDrops/elephant-goldfish-dining).
It adds the EGM Dining restaurant-selection workflow and its takeout-container
branding. It is not an official Google project, and Google does not maintain
or support this fork. The source remains under the Apache License 2.0 in
[LICENSE](../LICENSE).

## Which links belong to which repository?

- Install commands, current issues, pull requests, and support links in the
  user-facing docs should point to `RustyDrops/elephant-goldfish-dining`.
- Numbered issues, pull requests, and release records preserved in inherited
  design or verification documents refer to the upstream Google repository.
  They are historical references and are not issues or commitments of this
  fork.
- Upstream remains available at
  [github.com/google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model).

Use this fork's [issue tracker](https://github.com/RustyDrops/elephant-goldfish-dining/issues)
for current bugs and requests.
